# RIVANOX AppHub Store

Öffentlicher Plattformkatalog für ZimaOS, CasaOS und umbrelOS. **Keine installierbaren Apps, bis alle Produkt-Release-Gates erfüllt sind.** Dieses Repo ist unabhängig vom vorhandenen RIVANOX-UmbrelStore (R031).

Die Builds werden ausschließlich nach Workbench/Owner-Freigabe über die private Release Factory erzeugt. App-Images und Pakete für Endnutzer werden über GitHub/GHCR ausgeliefert; keine Gitea-Pulls durch Endnutzer.

Geplante Schnittstellen:
- ZimaOS: `store.json` via GitHub Pages (noch nicht freigeschaltet).
- CasaOS: `store/main.zip` via GitHub Pages (noch nicht freigeschaltet).
- umbrelOS: GitHub-Repository als Community-App-Store, erst nach Manifestfreigabe.
